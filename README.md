# Al Burr Fast Food — Online Ordering Web App

A fast, mobile-first restaurant ordering web application built with clean **HTML, CSS, and Vanilla JavaScript** — ready for instant deployment on **GitHub Pages** with zero build errors.

## Folder Structure
```text
alburr-fast-food/
├── index.html       # Main app structure (Splash, Customer Gateway, Menu, Cart Drawer)
├── style.css        # Modern dark-gold restaurant UI & animations
├── menu-data.js     # Complete Al Burr Fast Food menu items, sizes, prices & contact config
├── app.js           # Interactive filtering, quantity steppers, cart state & WhatsApp checkout
├── README.md        # Deployment instructions
└── assets/
    └── logo.svg     # Logo file (Replace with your 35805.jpg renamed to logo.jpg if desired)
```

## How to Use Your Exact JPG Logo
1. Copy your original logo image (`35805.jpg`) into the `assets/` folder and rename it to `logo.jpg`.
2. In `index.html`, replace `assets/logo.svg` with `assets/logo.jpg` (4 places).

## How to Deploy on GitHub Pages
1. Create a new public repository on GitHub (e.g., `alburr-fast-food`).
2. Upload `index.html`, `style.css`, `menu-data.js`, `app.js`, `README.md`, and the `assets/` folder directly to the root of your repository.
3. Go to **Settings → Pages → Build and deployment → Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, and click **Save**.
4. Your live ordering app will be online in ~1 minute!
